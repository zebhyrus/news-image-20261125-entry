One front page that sums up the world's news of Wednesday 25 November 2026:
two oil tankers ablaze in the Strait of Hormuz, Huawei convicted in a U.S.
fraud trial, Pakistan's first astronaut reaching orbit, Ukraine sinking a
Russian warship off Libya, all hostages freed in Cartagena, and Asian tech
shares tumbling.

The image is drawn entirely from code. `main.ts` (Node standard library
only) renders the 1024x1024 newspaper page pixel by pixel — masthead, six
stories, hand-drawn illustrations — and encodes the PNG itself. It runs
twice and writes the same bytes both times.

Run it:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
